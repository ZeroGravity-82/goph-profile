# Локальные TLS-сертификаты

Эта директория предназначена для локальной генерации TLS-сертификата сервера и его приватного ключа.

Сертификат `server.crt` и ключ `server.key` можно использовать для локального HTTP-сервера, если он доступен по имени
хоста или IP-адресу из сертификата, например `localhost` или `127.0.0.1`.

## Генерация

Из корня проекта выполните:

```bash
./certs/generate-local-certs.sh
```

Скрипт создаст локальный CA и подпишет им TLS-сертификат сервера.

## Какие файлы будут созданы

```text
certs/ca.key      - приватный ключ локального CA
certs/ca.crt      - самоподписанный сертификат локального CA
certs/server.key  - приватный ключ сервера
certs/server.csr  - заявка на выпуск серверного сертификата
certs/server.crt  - серверный сертификат, подписанный локальным CA
certs/server.ext  - параметры сертификата сервера, включая subjectAltName
certs/ca.srl      - служебный файл OpenSSL с серийным номером сертификата
```

Для запуска сервера нужны:

```text
certs/server.crt
certs/server.key
```

Для клиента нужен:

```text
certs/ca.crt
```

`ca.crt` нужен клиенту как корень доверия: через него клиент проверяет, что `server.crt` действительно подписан
локальным CA.

## Конфигурация сервера

В YAML-конфиге сервера укажите:

```yaml
tls_cert: certs/server.crt
tls_key: certs/server.key
```

То же самое можно задать через флаги:

```bash
--tls-cert=certs/server.crt --tls-key=certs/server.key
```

Или через переменные окружения:

```bash
GOPH_PROFILE_TLS_CERT=certs/server.crt GOPH_PROFILE_TLS_KEY=certs/server.key
```

## Конфигурация клиента

Для браузера, который открывает SPA, локальный CA должен быть доверенным в локальном окружении. Иначе браузер покажет
предупреждение о недоверенном сертификате.

## Hostname и subjectAltName

Скрипт генерирует сертификат для:

```text
DNS:localhost
IP:127.0.0.1
```

Это значит, что TLS-проверка пройдет при подключении к `localhost` или `127.0.0.1`.

Если сервер будет доступен по другому имени или IP, измените `subjectAltName` в `generate-local-certs.sh`.
После этого удалите старые сгенерированные файлы и запустите скрипт заново.

## Что не коммитить

Сгенерированные ключи и сертификаты не нужно коммитить:

```text
*.key
*.crt
*.csr
*.srl
```

Поэтому эти файлы исключены через `.gitignore` внутри директории `certs`.
